Both colour regions are traced from the original source pixels into transparent SVG paths. Flat slate/copper fills remove raster texture while retaining its shape; monochrome and reverse versions use the exact same paths. The main logo is an image-generated design, not a licensed Newsreader wordmark. Source contour accuracy is limited to the original 1536px raster and approximately 0.28px contour simplification, so these are faithful traced vectors, not newly reconstructed smooth Bézier masters.
