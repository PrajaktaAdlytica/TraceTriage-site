## Additional home composition rules

The offer chapter uses five `offer-motif-*` files on petrol, with all five named links; retain the supplied screenshot’s distinctions. Problem chapter uses `fragmented-workflow.svg` plus the conceptual ledger-gap photograph. Solution uses `trace-to-approval.svg`, `evidence-coverage.svg` and `crm-evidence-table.svg` as semantic HTML/SVG compositions. Use cases use the three persona hero figures. Trust uses the authority/data figures. Footer uses reverse logo and official inactive social entries.

Hero visual contract: home cinematic scene; why-change ledger gap; solutions role journey; portfolio suite topology; Desk incident correlation workbench; Review branching scope map; Proof deliberate approval boundary; Signal dual event/ingestion rail; Report document→evaluation transformation; platform shared architecture; results unmeasured scorecard; pricing hypothesis spread; request-demo qualification journey; sign-in access boundary; about architectural material detail plus principles; contact conversation routing; trust authority matrix; resources editorial library; integrations proposed-source topology; legal text-first information structure; 404 interrupted trace recovery. Avoid repeating one giant dashboard hero.

## Content completeness additions

Each product page follows inputs→workflow→output→controls→related offers, then product-specific FAQ and tailored tabletop CTA. Use clear editorial text/accordion, no obligatory decorative illustration on each FAQ answer. Products portfolio includes the five motif panels, each exact name, responsibility and link. Solutions overview introduces all three buyer routes. About uses supplied company facts only; no invented founder bio/team photos. Contact form uses minimum data and honest states. Legal figures illustrate draft coverage rather than pretending to be finished notices. Integrations include status labels and field mapping table, no “available now” marks.

## Responsive composition, not tiny screenshots

At widths below768px, display diagrams as stacked semantic steps; event rail becomes chronological list; scope map becomes12-account list; table has named horizontal-scroll region or record cards; coverage bars remain labeled at14px and a 8/3/1 summary is adjacent. Desktop motifs move from5 columns to2 then1, keeping product order. Main CTA stays visible in each hero. One illustration cannot be copied into every section to manufacture visual coverage.
