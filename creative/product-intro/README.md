# TraceTriage product intro assets

Start with `STORYBOARD.png` for the six-frame overview, then `REVIEW.html` for a local play/scrub motion storyboard. This kit replaces the earlier architecture-led concepts with a literal incident story.

| Folder / file | Contents |
|---|---|
| `frames/` | Six native 3840 × 2160 PNG composition masters |
| `svg/` | Six editable vector frames with named animation groups and editable text |
| `svg-outlined/` | Six font-independent vector masters, with the approved fonts outlined |
| `flow-plates/` | Six text-free material backplates, in PNG and SVG |
| `overlays/` | Six transparent exact foregrounds, in PNG and editable SVG |
| `assets/` | Approved primary/reverse logo, brand webfonts and font licenses |
| `STORYBOARD.md` | Meaning, timings, motion, voiceover, source and website integration notes |
| `FLOW-PROMPTS.md` | Copy-ready shot prompts and compositing instructions |
| `scenario.json` | The synthetic fixture used by the website |
| `manifest.json` | Frame names, dimensions and file paths |
| `QA.md` | Rendering and semantic checks, with limitations |

The approved story is: observed CRM change → linked cause → account scope and certainty → owner and evidence timeline → proposal awaiting human approval.

Images and motion storyboard are delivered. A final video has not been rendered in Google Flow, and this kit has not changed the live website.
